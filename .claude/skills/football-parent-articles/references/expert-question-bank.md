# Expert question bank

Companion to `expert-quotes.md`. That file logs the quotes we already have
and their reuse count; this file is the set of **questions to ask a new
expert**, mapped to the articles where an answer would plug a real E-E-A-T
gap. Built from the 2026-09-22 E-E-A-T audit (see `eeat/README.md`).

Use it when Graham lines up a real expert: match their background to a
recruit type below, then put the fitting questions to them. Every answer
comes back as a verbatim `<ExpertQA>` / `<ExpertOpinion>` callout with real
attribution, logged in `expert-quotes.md`, capped at 2-3 articles per quote.
Never invent an answer; these are prompts for a real person.

Legend: **★** = validated against the article in the 2026-09-22 proof batch.
**♻** = one answer is reusable across a whole cluster of articles.

## Recruit priority (by leverage)

1. Scout / recruitment lead — highest (trials cluster + reusable across the
   ~10 templated club dev-centre guides).
2. Girls-pathway coach (ETC/RTC) — weakest whole cluster, no expert yet.
3. Academy coach / manager — biggest cluster.
4. Sports scientist / physio — maturation cluster.
5. Sports psychologist — parent-support cluster (mostly a top-up).
6. Registered agent / intermediary — 2 high-trust articles.
7. Podiatrist / boot-fit — gear cluster (optional).

Already on file (don't re-request their topics): Martin Brock (JPL), Paul
Barry (Football DNA), FutureFit.
