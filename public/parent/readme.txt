FOOTBALL PARENT — BRAND ASSETS
Exported from the signed-off 11a (Parent) and 11b (Coach) sets.
Wordmark: Fira Sans Condensed Bold, all caps. Mark unchanged.

STRUCTURE

parent/                              coach/
  icon/    app icon, 1024–16px         icon/    same, with the COACH strip
  horizontal/  mark + 2-line wordmark  horizontal/
  stacked/     mark above wordmark     stacked/
  mono/        one-colour version      mono/

Each lockup comes in two inks:
  -ink    #201E1D type, for light backgrounds
  -white  white type, for dark backgrounds
Both are transparent PNGs. Numbers in filenames are pixel widths.

COLOURS
  Ink        #201E1D
  Yellow     #FFC400
  Coach      #3D86FF   (icon strip, wordmark on dark)
  Coach ink  #0B4FD1   (wordmark on light)

NOTES
  The Coach icon carries the COACH strip at 180px and above. Below that
  the strip is solid blue with no type, so it stays legible.
  These are raster PNGs. The source mark was supplied as a PNG, so a true
  vector (SVG/EPS) set needs the mark redrawn — ask if you want that.
